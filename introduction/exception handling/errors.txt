what are errors??
An error is a problem in a Python program that stops it from working correctly.
There are mainly 3 common types of errors:
1. compile time error Error
A compile-time error is an error found before the program runs, when the code is being translated/checked by the compiler
2. Logical Error
A logical error happens when the program runs without crashing but gives the wrong answer.

3. Runtime Error
A runtime error happens while the program is running.
